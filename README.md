# WebStack — Custom E-Commerce Stores & Software Solutions

Official web platform for WebStack Software Solutions, completely re-architected as a modern, high-performance React Single Page Application with full bilingual (Arabic & English) support, zero platform commissions, luxury gold and crimson executive design system, and an intelligent 24/7 AI customer service assistant.

## Core Features & Architecture

- **React 19 + TypeScript**: Modular component architecture (`src/components/`, `src/views/`, `src/data/`).
- **Bilingual Engine**: Instant Arabic (RTL) and English (LTR) language switching with persisted local preferences.
- **Client Portfolio & Showcases**:
  - **Larose Store** (`https://larose.salah-logistics.uk/`): Live client luxury fashion and cosmetics e-commerce store.
  - **Clean Al-Mithalia** (`https://clean-almithalia.salah-logistics.uk/`): Live client corporate platform in Saudi Arabia.
  - **Elsharkawy Farm Products** (`http://elsharkawy-farm.salah-logistics.uk/`): Interactive live food & dairy storefront.
  - **Al Handasiya Aluminum** (`http://handasiya-aluminum.salah-logistics.uk/`): Architecture workshop portfolio.
  - **Voltedge Beauty, Sports & Perfumes**: Live interactive retail store demos.
  - **Smart Shipping, AI Employees & n8n Automation**.
- **Interactive Project Modal**: Instant specs, tech stack breakdown, live showcase external links, and WhatsApp quote generators.
- **Ahmed AI Assistant**: Integrated 24/7 smart assistant capable of answering questions, qualifying leads, and seamlessly escalating to engineering on WhatsApp.
- **Zero Commission Philosophy**: Tailored quotes based on clean code architecture without rented SaaS limitations.
